Price settings & contract details

USD prices and 24-hour changes are automatically pulled from the deepest source-chain DexScreener pair for each payout asset (Ethereum for Ondo assets and BSC for TokensExpress assets). The last valid market result is saved in this browser and used if DexScreener is temporarily unavailable, so an API failure does not value an asset at zero. Source-chain and PulseChain liquidity are shown separately. A manual value always overrides auto pricing.

pSTONKS spot values use each token's primary pTOKEN/WPLS pool. Estimated sell values use live pool reserves, the contract's current sell fee, and PulseX V2's 0.29% swap fee. They include price impact but exclude gas and are estimates, not guaranteed quotes.

Read-only dashboard. It never requests a wallet signature and cannot move funds. Values depend on the contracts, PulseChain RPC availability, and market pricing source.
